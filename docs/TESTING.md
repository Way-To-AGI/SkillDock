# v1.3.0 测试记录

日期：2026-10-10。环境：macOS Apple Silicon、Python 3.14.6、Node 22.22.0。

## 自动化

- 27 项 Python 测试：目录注册及共享去重、环境变量、自定义路径、启发式发现和确认、忽略已移除目录、扫描边界、CRUD、原版本备份、外部编辑冲突、附件及执行权限、只读目录和系统技能、符号链接、回收站和恢复冲突。
- 7 项 Node 测试：三个入口的语法、HTML 转义、同名分组、接口请求与错误反馈、链接删除条件。
- 真实网络集成：skills.sh 搜索、Vercel 官方 find-skills 的 GitHub 预览、临时目录安装及来源哈希。

## 界面操作

通过隔离 home 和 store，在实际浏览器界面完成未知目录确认、新建、编辑保存、跨 Agent 复制、删除、撤销恢复、搜索、远程搜索、预览、安装和目标列表折叠。还验证了批量复制、批量删除及从回收站恢复。测试文件不写入用户真实技能目录。

打包后的 Electron v1.3.0 macOS arm64 应用已在隔离 store 下成功启动并显示技能列表。

## 边界

自动化测试验证路径规则和文件操作，并未逐个运行 77 类 Agent 检查其实际加载。目录约定会随产品版本变化；启发式扫描受目录深度、数量和时间上限限制，不扫描项目目录。当前发布包为未签名的 macOS arm64 应用，其他系统的桌面打包尚未验证。

复现：`npm test`；网络集成单独运行 `npm run test:network`。
