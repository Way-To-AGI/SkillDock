## 边界

自动化测试验证路径规则和文件操作，并未逐个运行 77 类 Agent 检查其实际加载。目录约定会随产品版本变化；启发式扫描受目录深度、数量和时间上限限制，不扫描项目目录。当前发布包为未签名的 macOS arm64 应用，其他系统的桌面打包尚未验证。

复现：`npm test`；网络集成单独运行 `npm run test:network`。
